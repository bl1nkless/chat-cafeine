# Chat Caféiné — сайт + админка

Сайт по макетам из папок `01_…`–`06_…`, сведённый в **одну дизайн-систему**: одинаковые шапка, подвал,
шрифты, кнопки, карточки и отступы на всех страницах. Полностью адаптивный. Никаких зависимостей — нужен только **Node.js 18+**.

## Запуск

```bash
cd site
npm start            # http://localhost:3000
```

На Mac можно просто дважды кликнуть `start.command`.

* Сайт: http://localhost:3000
* Админка: http://localhost:3000/admin — пароль по умолчанию **chatcafeine** (сразу смените в «Пароль и копии»)
* Другой порт: `PORT=8080 npm start`. Свой стартовый пароль: `ADMIN_PASSWORD=... npm start` (только при первом запуске).

## Что работает

* **Корзина**: «+» / цена / «Ajouter au panier» добавляют товар, иконка сумки показывает количество, корзина хранится в браузере.
* **Оформление заказа**: имя, телефон, день и время самовывоза (только в рабочие дни и часы), комментарий → заказ попадает в админку. Либо одной кнопкой уходит в WhatsApp с готовым списком.
* **Заказ торта**: форма → «Заявки на торты»; клик по карточке торта подставляет модель в форму.
* **Контакты**: форма → «Сообщения»; e-mail, телефон, Instagram, Google Maps кликабельны.
* **WhatsApp** везде открывает чат с готовым текстом.
* Липкая шапка, мобильное меню (бургер), карусели на мобильной главной, быстрые переходы по разделам меню, «хлебные крошки» на товаре, лайтбокс в галерее.
* Защита: honeypot и лимит отправок от спама, пароль хранится в виде хеша, сессия в HttpOnly-cookie.

## Дизайн-система

| Что | Правило |
|---|---|
| Шрифты | **Fraunces** — все заголовки, **DM Sans** — весь остальной текст |
| Размеры текста | 9 токенов: `display`, `h1`, `h2`, `h3`, `lead`, `body`, `sm`, `xs`, `kicker` |
| Цвета | токены `--bg`, `--bg-alt`, `--surface`, `--ink`, `--text`, `--muted`, `--accent`, `--caramel` |
| Отступы | одно поле по бокам `--pad`, один ритм секций `--sec`, одна сетка карточек `--gap` |
| Масштаб | телефон — пиксели; компьютер — единица `u` (1u = 1px макета шириной 1440), с минимальными размерами для читаемости |
| Мотив | **арка**: фото товаров, торты, фото на странице товара — с полукруглым верхом |
| Сдержанность | без теней-карточек, иконок в кружках и капса над заголовками; разделители — тонкие линии |

Каждая страница собирается из одних и тех же блоков: **hero** (вступление), **sec** + **sh** (секция с заголовком),
**split** (текст + фото), **rail/pc** (ряд карточек), **mlist/mi** (строки меню), **facts** (адрес, часы, состав),
**form/fld/panel** (формы).

### Что видит посетитель

- **Открыто / закрыто** — считается по времени Парижа из часов в админке: в верхней строке, на главной, в контактах, в подвале, в корзине.
- **Кнопка «Ajouter»** превращается в «− 2 +», как только товар в корзине; кнопка в шапке показывает сумму («Panier · 9,00 €»).
- **На телефоне** внизу появляется панель корзины, когда в ней что-то есть.
- **Меню** — все товары на одной странице, панель разделов прилипает к шапке и подсвечивает текущий.
- **Страница товара** — выбор количества, «уже в корзине», адрес самовывоза и статус работы рядом с кнопкой.

## Структура кода

```
server.js                маршруты, API, сборка CSS
lib/
  store.js               хранение данных + миграции контента (content.version)
  auth.js                пароль и сессии админки
  defaults.js            контент по умолчанию
  views/
    util.js  icons.js    экранирование, картинки, иконки
    ui.js                общие компоненты (hero, заголовки секций, карточка товара, формы)
    chrome.js            общий каркас: шапка, подвал, корзина, мобильное меню
    pages/*.js           по файлу на страницу — описывают только содержимое <main>
public/
  css/00-tokens.css      токены дизайна
  css/01-base.css        сброс и типографика
  css/02-components.css  компоненты
  css/03-chrome.css      шапка, подвал, корзина, меню
  css/04-layout.css      композиции hero и split
  css/pages/*.css        только то, что уникально для страницы
  js/site.js             корзина, формы, меню, карусели, галерея
  admin/                 админка
```

Сервер склеивает все CSS-файлы по порядку в один `/css/site.css`.

## Админка (для владелицы)

* **Входящие** — заказы, заявки на торты, сообщения: статусы (Новый → Подтверждён → Готов → Выдан), заметки, телефон/WhatsApp клиента в один клик. Счётчик новых, автообновление раз в 30 секунд.
* **Товары** — цены и «показывать на сайте» прямо в таблице; полный редактор: фото (загрузка с телефона, сжимается автоматически), описания, ингредиенты, слои «en détails», практическая информация, «À goûter aussi». Добавление/удаление товаров, порядок.
* **Разделы меню**, **все тексты и фото всех страниц**, торты (название, цена, цвет плашки, фото), шаги «Comment ça marche», галерея.
* **Настройки** — телефон, WhatsApp, e-mail, адрес, ссылка на карту, часы работы и дни самовывоза, соцсети, строка объявлений над шапкой, логотипы, пункты навигации (один список для шапки, подвала и мобильного меню).
* **Telegram-уведомления** о каждом заказе/заявке: вставить токен бота и chat id → «Проверить».
* **Резервные копии**: 30 последних версий хранятся автоматически (`data/backups`), можно скачать/загрузить JSON или вернуть всё «как в макете».

Все данные лежат в `site/data/` (контент, заказы, загруженные фото) — эту папку и нужно бэкапить при переносе.

## Выкладка в интернет

Любой хостинг с Node.js (VPS, Render, Railway, Fly.io): загрузить папку `site`, команда запуска `npm start`, переменная `PORT` подхватывается автоматически. Нужен постоянный диск для `data/`. За HTTPS-прокси cookie админки становятся `Secure` автоматически.
